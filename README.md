# Análise de Acidentes nas Rodovias Federais Brasileiras

Projeto acadêmico desenvolvido para a disciplina de Tópicos de Big Data.

## Tema

Análise das causas e fatores associados à gravidade dos sinistros de trânsito nas rodovias federais brasileiras.

## Objetivo

Analisar dados de acidentes registrados pela Polícia Rodoviária Federal (PRF), buscando identificar padrões relacionados às causas dos acidentes, gravidade, condições meteorológicas, veículos, localização e evolução temporal.

## Fonte dos dados

Dados abertos da Polícia Rodoviária Federal (PRF).

## Período analisado

- 2020 a 2025: anos completos
- 2026: janeiro a julho

## Tecnologias utilizadas

- Python
- Pandas
- Matplotlib
- Power BI
- Git/GitHub
